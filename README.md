# NLP-Emotion-Classification

## Project Overview
This project is based on Natural Language Processing (NLP) and Machine Learning.

The system predicts human emotions from text messages such as:
- Joy
- Sadness
- Anger
- Fear
- Love
- Surprise

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- NLP

## Features
- Text preprocessing
- Emotion prediction
- Data visualization
- Machine learning model training
- Accuracy evaluation

## Dataset
The dataset contains text sentences with emotion labels.

## Project Workflow
1. Load Dataset
2. Clean Text
3. Feature Extraction
4. Train Model
5. Evaluate Accuracy
6. Predict Emotion

## How to Run
1. Open the notebook in Jupyter Notebook or Google Colab
2. Install required libraries
3. Run all cells

## Output Example
Input:
"I am very happy today"

Prediction:
Joy
